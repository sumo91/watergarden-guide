# 水庭引路人 · The Watergarden

一个可在手机浏览器中游玩的 3D 护送小游戏。驾驶小舟、鸣铃聚拢灵鱼，将三群鱼带回灯池，让沉睡的水庭重新亮起。

## 游玩

- 手机：拖动左下摇杆划船，点击右下铜铃；也可以直接点击水面前往。
- 电脑：WASD / 方向键，空格鸣铃，Shift 慢行，Esc 暂停；支持点击水面划船。
- 靠近灵鱼 5.8 米以内鸣铃，鱼群会跟随。连续快划或绕行礁石时可能掉队，回头鸣铃可以找回。
- 每个灯池至少送回 18 / 24 尾鱼，停留片刻点亮古灯。三座灯池全部点亮即通关。
- 小地图与菱形标记指向当前目标。点亮灯池后会开花，水色也会更清澈。
- 暂停、关闭页面和每隔数秒都会自动保存。存档与最佳成绩只保存在当前浏览器，清除网站数据会清除记录。
- 通关后可继续自由划船，或者重新挑战完整护送与时间记录。

## 本地运行

需要 Node.js 22 与 pnpm 10 或更高版本。

```sh
pnpm install
pnpm dev --port 5200
```

打开 `http://127.0.0.1:5200/`。若要在同一 Wi-Fi 下用手机测试，可运行 `pnpm dev --host 0.0.0.0 --port 5200`，再用电脑的局域网 IP 访问。日常运行默认仅监听本机。

```sh
pnpm test
pnpm build
pnpm preview --port 5200
```

## GitHub Pages

仓库内已包含 `.github/workflows/deploy.yml`，推送 `main` 后依次安装依赖、运行游戏逻辑测试、构建，并发布 GitHub Pages。仓库的 Settings → Pages → Source 使用 **GitHub Actions**。

当前 Pages 路径配置为 `/watergarden-guide/`，更换仓库名时需同步修改 `vite.config.js` 中的 `base`。发布不需要常驻后端，所有玩法与存档均在浏览器运行。

## 画质与移动设备

首次打开会根据触控环境或窗口宽度选择画质。暂停菜单可选择省电、均衡或精细；切换后重新载入并保留存档。自动模式在检测到低帧率时降低渲染分辨率。

省电档降低草量、阴影分辨率、折射与反射目标尺寸，关闭多重采样与接触遮蔽，保留水色吸收、深度柔化、倒影、尾浪和风动。页面失焦或切到后台会自动暂停。

需要支持 WebGL 2 的浏览器。桌面浏览器与手机尺寸的交互检查不能代替 iOS / Android 真机性能测试；持续 30 帧是优化目标，并非对所有手机的保证。

## 文件组织

| 文件                                                 | 用途                                             |
| ---------------------------------------------------- | ------------------------------------------------ |
| `src/game.js`                                        | 独立于画面的移动、碰撞、鱼群、任务、存档规则     |
| `src/game-world.js`                                  | 灵鱼、灯池、花朵、急流提示、鸣铃效果             |
| `src/input.js`                                       | 多点触控摇杆、键盘、点击移动                     |
| `src/main.js`                                        | 镜头、界面、渲染、存档与画质管理                 |
| `src/audio.js`                                       | Web Audio 合成铜铃与通关和弦                     |
| `src/world.js`, `src/flora.js`, `src/hut.js`         | 程序化地形、道具、植物、小屋                     |
| `src/water*.js`, `src/materials.js`, `src/finish.js` | 水面、材质、深度扩散与调色                       |
| `tests/game.test.js`                                 | 边界、掉队找回、存档、任务结算和完整护送路线测试 |

模型、着色器、界面和声音均由本项目生成，无远程模型、字体或音频服务依赖。原始场景研究参考、开发截图和迭代备份不进入发布仓库。
